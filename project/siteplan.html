Trail Explorer - Site Plan

Pierre Phil D. Bangay

WDD 131 - Dynamic Web Fundamentals

1. Site Name

Site Name: Trail Explorer

Reasoning: "Trail Explorer" is concise, memorable, and directly communicates the core theme of the website-discovering local outdoor hiking and biking trails. It appeals to both local residents and visiting outdoor enthusiasts looking for reliable route information.

Optional Domain Availability: trailexplorerguide.org

2. Site Purpose

The primary purpose of Trail Explorer is to serve as an accessible, central hub for local trail information. It helps outdoor enthusiasts discover regional hiking and biking paths, assess route difficulties, check distance and terrain specs, and save custom trail preferences. Additionally, it offers a contact/feedback form for users to request route recommendations or submit trail condition updates.

3. Target Audience Scenarios

  • Scenario 1: "Where can I find moderate-level mountain biking trails near me that have loop options and parking facilities?"
  • Scenario 2: "How can I filter local hiking trails by distance and save my favorite paths so I can review them later?"
  • Scenario 3: "How can I get in touch with local trail guides or report a fallen tree on a specific trail?"

4. Color Schema

The color palette is inspired by natural, outdoor landscapes to reflect the trail theme while maintaining high contrast for accessibility (WCAG AA compliant).

#2E5A36 Primary Accent (Header, Navigation, Buttons)
#8B5A2B Secondary Accent (Subheadings, Hover States)
#F7F9F6 Background (Page Body, Card Canvas)
#1E231F Text Color (Body Copy, Main Headings)

5. Typography

The site uses two web fonts from Google Fonts to ensure legibility across screen sizes:

  • Montserrat (Bold 700 / Semi-Bold 600) - Used for main headings (<h1>, <h2>, <h3>), main title banners, and primary navigation links.
  • Open Sans (Regular 400 / Semi-Bold 600) - Used for paragraph body text, form field labels, list items, and footer metadata.
